这张图给出 MOSS 平台的系统总体架构，采用四层分层设计。最上面是表示层，由 React 前端单页应用承担交互。第二层是应用层，也就是 Backend FastAPI 服务，包含 REST 路由、SocialRecSys 推荐服务、时间与内容管理，以及 SentenceTransformer 嵌入。第三层是 Agent 层，由 AgentGraph 调度、决策循环加记忆系统、以及 LangChain 大小模型分层驱动构成。最下面是数据与配置层，包括 SQLite 加 sqlite-vec 的向量存储、作为配置中枢的 calibration_profile.yaml，以及 runs 运行归档。旁边的离线分析模块产出画像与校准配置，驱动在线运行。整体上各层解耦，离线产物通过配置驱动在线，职责清晰、易于扩展。
