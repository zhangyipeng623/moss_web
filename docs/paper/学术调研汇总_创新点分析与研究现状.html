1. 研究背景与核心问题

1.1 问题缘起

社交媒体已成为社会运动、公共舆论和政治传播的核心平台。从 #MeToo 到 #BlackLivesMatter，社交网络上的信息传播和舆论演化深刻影响着现实世界。 然而，预测大规模用户群体对特定事件的响应——包括态度变化、内容传播路径、群体极化程度——仍是一个开放性的科学挑战。

传统方法依赖回溯性分析（retrospective analysis），通过事后数据总结规律，但缺乏前瞻性预测能力。 近年来，大语言模型（LLM）的涌现为构建具有类人行为能力的智能体（Agent）提供了可能，使得社会科学模拟进入新范式。 然而，如何将 LLM Agent 的逼真性与 ABM 的可扩展性有机结合，如何在离线校准与在线部署之间建立可信的参数传递链路，如何用传播学和认知科学理论指导模拟系统的工程设计，仍是领域核心难题。

2. 国际研究现状

2.1 发展脉络

2000–2020 · 纯 ABM 时代

Bounded Confidence Model (Deffuant 2000)、Social Judgement Theory (Sherif & Hovland 1961)、SIR 传播模型（Bettencourt 2006）主导。Epstein & Axtell (1996) 的 Growing Artificial Societies 奠定方法论基础。优势在于可扩展性和数学可分析性，但缺乏语言级行为细节。

2023 · LLM Agent 萌芽

Park et al. 的 "Generative Agents" (UIST 2023) 开创先河——记忆流 + 反思 + 计划的架构成为后续工作的基础模板。25 个 Agent 在模拟小镇中展现出类人社会行为。

2024 · Hybrid 框架涌现

HiSim (ACL 2024 Findings) 提出 Core User (LLM) + Ordinary User (ABM) 二分混合架构。OASIS 用 Llama3-8B 实现百万级 Agent 模拟。FDE-LLM (Nature Sci Reports) 提出 CA+SIR+LLM 三层混合。Törnberg et al. 利用 LLM 评估不同新闻推荐算法。YSocial 发布开源社交媒体数字孪生平台。

2025 · 规模化+动态化+理论化

SALM 实现 4000+ 轮次稳定模拟，节省 73% token，给出人格稳定性形式化保证。DynamiX 引入动态角色切换和社会关系演化。Light Society 实现十亿 Agent 模拟。AgentSociety 用万级 Agent 研究极化和外部冲击。SoMe Benchmark (AAAI 2026) 建立首个综合性社交媒体 Agent 评估基准。SocioVerse（复旦）构建千万用户池的世界模型。SAGE 和 MARS 将 Ebbinghaus 遗忘曲线与 LLM Agent 记忆系统深度整合。MOSS（本工作）提出了不同于 HiSim 等 Hybrid 框架的技术路线：ABM 仅用于离线阶段的推荐参数反推（Dirichlet-EM 校准），在线模拟阶段全部用户均为 LLM Agent——L4-L5（Innovators + Early Adopters）使用大模型驱动，L1-L3（Early/Late Majority + Laggards）使用小模型驱动，形成"分层 LLM Agent"范式。

4. 现有研究的优势

4.1 方法论层面的优势

4.1.1 混合架构成为成熟范式（HiSim、FDE-LLM）；分层 LLM Agent 成为差异化路线（MOSS）

HiSim、FDE-LLM 等系统验证了"Core LLM + Ordinary ABM"混合架构的有效性——将 LLM 的语言生成和推理能力与 ABM 的计算可扩展性有机结合。 FDE-LLM 的 CA+SIR+LLM 三层结构进一步细化了混合层次，CA 约束防止 LLM 过度反应，SIR 模拟意见疲劳和自然衰减。

MOSS 提出了另一条技术路线：不将任何用户简化为数学公式驱动——在线模拟阶段全部用户均为 LLM Agent，通过 Rogers 理论指导的分层策略控制成本：L4-L5（前 16% 高影响力用户）使用大模型获得高保真度行为，L1-L3（后 84% 大众用户）使用小模型 + 预设行为模板获得经济性。ABM 在 MOSS 中的角色被严格限定为离线推荐参数反推引擎，而非在线用户模拟器。

4.1.2 规模化能力快速提升

从 2023 年 Generative Agents 的 25 个 Agent，到 2024 年 OASIS 的百万级，再到 2025 年 Light Society 的十亿级——模拟规模在两年内提升了七个数量级。 MIT 的 LLM Archetypes 技术（预计算行为原型，百万 Agent 引用而无需逐次调用 LLM）代表了规模化路线的前沿。

4.1.3 评估体系开始系统化

HiSim 的 SoMoSiMu-Bench 从微观（立场/内容/行为对齐）和宏观（态度分布/DTW 时间序列）两个层面建立了结构化的评估框架。 SoMe Benchmark (AAAI 2026) 进一步扩展到 8 任务、32 平台，代表评估标准化的最新进展。 Münker et al. (2025) 的工作提出了 TWONs 形式化验证框架，对"模拟是否真的拟真"进行了批判性审视。

4.1.4 认知科学开始融入

SAGE (2025, Neurocomputing) 和 MARS (2025) 将 Ebbinghaus 遗忘曲线深度整合到 LLM Agent 记忆系统中， Microsoft (2026) 的仿生记忆六机制代表了此方向的最前沿。认知科学不再仅仅是"灵感来源"，而是正在成为可计算、可验证的系统组件。

5. 现有研究的不足与空白

5.1 六大研究空白

空白 1：缺乏从真实数据到模拟部署的完整闭环校准 ⭐⭐⭐

现状：HiSim 的参数校准在纯 ABM 上进行（因 LLM 成本过高无法直接在混合模型上校准），然后将参数"迁移"到混合模型。 这存在分布偏移（Distribution Shift）问题——纯 ABM 环境下的最优参数未必是混合模型环境下的最优参数。 FDE-LLM 甚至没有自动校准机制，依赖 LLM 角色扮演。 SALM 和 DynamiX 根本不涉及参数校准。

MOSS 的填补：向量化 ABM 引擎本身就是为校准设计的，支持在真实内容传播数据上直接进行 EM 搜索。 校准结果通过 calibration_profile.yaml 自动注入在线 SocialRecSys，无需手工迁移参数。 Per-Batch Min-Max 归一化保证了离线 ABM 评分与在线 Feed 评分的数学一致性。

空白 2：用户画像在模拟中的动态演化未被充分建模 ⭐⭐⭐

现状：绝大多数工作（HiSim、FDE-LLM、OASIS、SALM）将用户画像视为初始化后不可变的静态参数。 即使 Agent 在模拟中态度发生了偏移，其 Profile 描述仍保持不变。 EVOLVE (2024) 和 EVOLVE-X (2025) 做了用户演化预测，但预测的是真实用户未来状态，而非在模拟中建模画像的动态变化。 SPARK (2025) 开始探索立场共演化，但仅限于立场维度，不涉及整体画像。

MOSS 的潜力：已具备画像演化的基础设施——AgentState（每轮更新情绪/目标/关注话题/立场摘要）、Soft Backfire 信念更新（量化立场变化）、EventMemory（记录演变轨迹）。 可扩展为完整的画像动态演化机制。

空白 3：推荐系统参数校准在模拟领域被忽视 ⭐⭐⭐

现状：几乎所有社交媒体模拟工作关注的是用户态度/内容/行为的模拟，而非平台推荐算法本身的参数校准。 推荐系统校准（如 RecLLM-R1 的 GRPO、MUMA 的 Bandit+Causal 框架）和社交模拟是两条几乎不交汇的研究线。 MOSS 同时做了两件事——模拟用户行为 + 反推最优推荐参数——这是一个独特的交叉视角。

空白 4：大规模模拟中的理论驱动异质性表示 ⭐⭐

现状：HiSim 将用户二分（Core 300 + Ordinary 700），缺乏理论依据——为什么是 300/700 而非 200/800？ FDE-LLM 同样是 Leader/Follower 二分。 SALM 用了分层 Prompt 但没有理论驱动的分层依据。 SocioVerse 做了人口分布对齐但未将分层理论化为系统设计的原则。

MOSS 的填补：Rogers 5 级创新扩散理论为分层比例提供了传播学理论基础——P84 阈值对应 Innovators+Early Adopters ≈ 16%， 不同层级使用不同信息粒度的画像表示（L4-L5 用 9 字段详细画像，L1-L3 用 3 字段简化模板），是"理论驱动 + 数据结构分层"的双重创新。

空白 5：信念更新的认知心理学基础薄弱 ⭐⭐

现状：现有工作的信念更新多采用 Bounded Confidence（距离小于阈值则受影响）或 SIR 模型（感染-恢复）。 这些模型不建模认知失调（Cognitive Dissonance）——当个体接触与其既有信念冲突的信息时可能反而强化原有立场。 Kovács et al. (2024-2025, Scientific Reports) 已从理论上证明认知失调避免可以自发产生极化， 但这一发现尚未被整合到面向应用的 LLM Agent 模拟系统中。

MOSS 的填补：Soft Backfire 机制直接将 Nyhan & Reifler (2010) 的逆火效应发现——立场冲突时极端用户有概率反而强化原有立场——转化为可计算模型。

空白 6：LLM Agent 记忆系统的认知保真度 ⭐

现状：SAGE 和 MARS 的 Ebbinghaus 遗忘机制主要面向通用推理任务，未针对社交模拟场景优化。 大多数社交模拟系统的记忆管理仍是启发式的（固定窗口、简单截断）。 SALM 的注意力记忆系统虽高效，但其 80% 缓存命中率来自固定规则而非认知模型。

MOSS 的填补：乘法评分公式（importance × decay × (1+boost)）保证了 Agent 自主判断的重要性始终是主信号——衰减因子调节但不主导——这一设计原则在现有文献中未见报道。

MOSS 是一个端到端的社交媒体模拟推演平台，包含三个核心模块——用户画像生成（离线 LLM 流水线）、推荐参数反推（离线 ABM+EM 校准）、Agent 模拟运行（在线分层 LLM Agent）——它们通过 calibration_profile.yaml 单一配置文件构成完整的数据-校准-运行闭环。

关键架构决策：与 HiSim/FDE-LLM 的"Core LLM + Ordinary ABM"混合范式不同，MOSS 的 ABM 引擎仅用于离线推荐参数反推，不参与在线用户模拟。 在线模拟阶段全部用户均为 LLM Agent：L4-L5（Rogers 定义的 Innovators + Early Adopters，前 16%）使用大模型驱动，L1-L3（Early/Late Majority + Laggards，后 84%）使用小模型驱动。 这种"全 LLM Agent + 分层模型"的设计保证了所有用户都具有语言级行为逼真度，同时通过 Rogers 理论指导的模型分层控制成本。 技术上采用 multiprocessing 双进程架构（FastAPI Backend + AgentGraph），LangChain ChatOpenAI 驱动 Agent 决策，SentenceTransformer + sqlite-vec 提供语义向量检索，并通过 Pydantic 模型体系保证全链路配置校验。

7. 创新点深度分析

创新点 A：从真实数据到模拟部署的端到端闭环校准方法论 核心贡献

一句话描述：提出并实现了"原始社交数据 → LLM 画像生成 → Rogers 分层 → 向量化 ABM 参数反推 → Dirichlet-EM 联合校准 → 统一 YAML 配置注入 → 在线 Agent 模拟"的完整闭环方法，解决了离线校准到在线部署的参数对齐这一领域性难题。

为什么是创新：

  • HiSim 的校准只能在纯 ABM 上进行（因 LLM 调用成本过高），存在分布偏移问题。MOSS 的 ABM 引擎本身为向量化校准设计，在语义空间直接校准，不受 LLM 调用次数限制。
  • FDE-LLM 无自动校准机制；SALM、DynamiX、OASIS 根本不涉及参数校准。
  • calibration_profile.yaml 作为单一配置中枢，实现离线校准参数到在线推荐系统的零手工自动注入——这在现有文献中未见报道。
  • Per-Batch Min-Max 归一化保证了离线 ABM 与在线 Feed 评分公式的数学一致性——这是校准可迁移性的关键保障。
  • 现有推荐系统校准（RecLLM-R1 GRPO、MUMA Bandit）与社交模拟是两条不交汇的研究线，MOSS 的交叉视角是独有的。

学术贡献表述建议（英文）：

"We propose a closed-loop calibration methodology that bridges offline ABM-based parameter inference and online LLM-agent-based simulation through a unified configuration interface. Unlike prior hybrid frameworks (e.g., HiSim) that calibrate ABM parameters in simplified environments and heuristically transfer them to the hybrid system, our approach performs calibration directly in the semantic space using a vectorized ABM engine with Dirichlet-constrained EM optimization, and automatically injects the calibrated parameters into the live recommendation system via a single YAML configuration file."
新颖性:
高 — 弥补领域关键空白
可行性:
已实现 — v2 重构已完成闭环
工作量:
需要补充实验验证（ablation + baseline comparison）

创新点 B：Rogers 创新扩散理论驱动的分层用户画像体系 核心贡献

一句话描述：以 Rogers 5 级创新扩散理论为组织框架，构建差异化粒度的用户画像体系——P84 阈值自动识别前 16% 高影响力用户（Innovators + Early Adopters），通过完整五阶段 LLM 流水线生成 9 字段详细画像；后 84% 大众用户使用基于层级行为预设（TIER_BEHAVIOR）的简化模板。

为什么是创新：

  • HiSim 的二分法（300 Core + 700 Ordinary）缺乏理论依据——为什么是这个比例？MOSS 的 P84 阈值来自 Rogers 理论中 Innovators+Early Adopters 合计约 16%，是传播学理论驱动而非经验驱动。
  • SALM 的分层 Prompt 共享（全局/群体/个体层）是文本层面的优化，MOSS 的画像数据结构本身分层（9 字段 vs 3 字段）——这是一个不同的、更根本的贡献维度。
  • 2025 年的 Population-Aligned Persona 工作强调了人口分布对齐的重要性，但其"对齐"是在统计层面（大五人格分布），而非在信息传播动力学层面（谁驱动了创新的扩散）。
  • Computational DOI models (Social Network Analysis and Mining, 2025) 验证了在扩散模型中使用 Rogers 分类的效用，为 MOSS 的分层设计提供了独立的学术验证。
新颖性:
较高 — 理论驱动分层 + 数据结构分层双重创新
可行性:
已实现 — 三种 profile_mode + 双 Prompt 体系
工作量:
需要理论阐述 + 对比实验（Rogers 5 级 vs 二分 vs 无分层）

创新点 C：模拟过程中的用户画像动态演化 推荐新增

一句话描述：在 Agent 模拟运行过程中，追踪并更新用户画像的关键维度（立场、兴趣、情绪、影响力层级），实现"用户画像不是静态初始化参数，而是在社交互动中持续演化的动态表征"。

为什么是创新：

  • 现有工作（HiSim、FDE-LLM、OASIS、SALM、DynamiX）都将用户画像视为初始化后不可变的。即使态度偏移，Profile 文本描述仍保持不变。
  • EVOLVE (2024) 和 EVOLVE-X (2025) 预测真实用户的演化阶段，但在模拟中不进行画像演化。
  • MOSS 已具备基础设施：AgentState（每轮更新）、Soft Backfire（量化立场变化）、EventMemory（演变轨迹）。
  • 可对比"有画像演化" vs "无画像演化"的长期模拟保真度差异——这是一个独特且有说服力的实验设计。
新颖性:
高 — 领域空白，教师明确建议的方向
可行性:
需要新增画像增量更新功能
工作量:
中等（实现 5-7 天 + 实验设计）

创新点 D：认知科学驱动的记忆检索与信念更新机制

一句话描述：在在线 LLM Agent 的记忆检索中引入 Ebbinghaus 遗忘曲线的指数衰减和乘法评分公式（importance × decay × (1+boost)）；在离线 ABM 校准引擎的信念更新中引入基于 Nyhan & Reifler 逆火效应的 Soft Backfire 机制（立场冲突时极端用户有概率反向强化原有立场），使校准过程更贴近真实社交网络的舆论动力学。

为什么是创新：

  • SAGE (2025) 和 MARS (2025) 的 Ebbinghaus 遗忘机制面向通用推理任务。MOSS 的乘法评分公式保证了 Agent 自主判断的重要性始终是主信号——衰减调节但不主导。这一设计原则在现有文献中未见明确讨论。
  • Soft Backfire 机制在社交媒体模拟中尚未被广泛采用。FDE-LLM 的 SIR 建模了"意见疲劳/衰减"但不建模"逆火"。
  • Kovács et al. (2024, Scientific Reports) 从理论上证明了认知失调可以自发产生极化，但该发现未被整合到面向应用的 LLM Agent 模拟系统中——MOSS 的 Soft Backfire 填补了这一理论与应用的鸿沟。
  • Monti et al. (KDD 2020) 的"Learning Opinion Dynamics from Social Traces"已展示了从真实数据中恢复 latent opinion trajectories 的可行性，并验证了 backfire effect 的存在。
新颖性:
中高 — 概念非全新但整合方式独特
可行性:
已实现
工作量:
需要 ablation study

创新点 E：大规模异质性用户的可控模拟

一句话描述：基于 Rogers 5 级的 1500+ Agent 分层 LLM 模拟——L4-L5（Innovators + Early Adopters）由大模型驱动，使用 9 字段详细画像；L1-L3（Early/Late Majority + Laggards）由小模型驱动，使用 3 字段简化画像 + TIER_BEHAVIOR 预设行为。通过 calibration_profile.yaml 中 simulation 段统一控制各层级用户的在线活跃概率（p_online）、记忆参数、信念更新参数。

为什么是创新：OASIS 追求百万级规模但所有 Agent 使用同一模型，牺牲了个体异质性；HiSim 的 Ordinary Users 是数学公式驱动的 ABM（缺乏语言行为）；Generative Agents 局限于 25 个 Agent。MOSS 首创"全 LLM Agent + 分层模型驱动"范式——所有用户都具有语言级行为逼真度，同时通过 Rogers 理论指导的差异化模型配置控制成本。在"规模保真度谱系"中占据了一个独特的平衡点。

中等 — 分层异质性控制是特色
可行性:
已实现

8. 与最相关工作的详细对比

8.1 MOSS vs HiSim（教师 PPT 参考框架，最相关）

MOSS（本工作）

  • 在线驱动方式：全部用户均为 LLM Agent——L4-L5 大模型（9 字段画像），L1-L3 小模型（3 字段画像+预设行为）。ABM 仅用于离线参数反推。
  • 画像生成：五阶段 LLM 流水线（证据抽取→稳定画像→行为画像→Agent 画像→模拟初始状态）
  • 用户分层：Rogers 5 级理论驱动 + P84 单阈值自动切分 + 分层画像粒度（9 字段 vs 3 字段）
  • 参数校准：向量化 ABM + Dirichlet-EM 在语义空间直接校准，不受 LLM 调用限制
  • 在线注入：calibration_profile.yaml 单一文件 → SocialRecSys.configure() 零手工注入
  • 评分一致性：Per-Batch Min-Max 归一化保证离线 ABM 与在线 Feed 数学语义一致
  • 信念更新：Soft Backfire 建模逆火效应（立场冲突时极端用户可能反向强化）
  • 记忆系统：Ebbinghaus 指数衰减 + 乘法评分公式（重要性为主，衰减调节）
  • 校准目标：推荐参数 + 用户行为 联合校准

HiSim (ACL 2024 Findings)

  • 在线驱动方式：Core Users（~300）由 LLM 驱动；Ordinary Users（~700）由 ABM 数学公式驱动——后者缺乏语言生成能力，仅有态度数值更新
  • 画像生成：手工设计的 Profile Module（人口统计+社交特征+传播角色），非 LLM 流水线
  • 用户分层：经验二分（300 Core + 700 Ordinary），无理论驱动的分层比例
  • 参数校准：在纯 ABM 上进行参数扫描 → 将参数"迁移"到混合模型（分布偏移问题）
  • 在线注入：无自动化配置注入机制
  • 评分一致性：无归一化对齐策略
  • 信念更新：Bounded Confidence / Social Judgement 标准 ABM 模型
  • 记忆系统：基础 Memory Module（写入+检索+反思），无认知衰减
  • 校准目标：仅关注用户行为模拟，不涉及推荐系统
关键差异总结：HiSim 是社交媒体模拟的奠基性工作（混合框架 + SoMoSiMu-Bench），但其设计多处依赖经验判断。 MOSS 在五个维度上提供了理论驱动或方法论的增强：(1) 校准闭环（消除分布偏移）；(2) 传播学理论驱动的分层； (3) 认知科学驱动的记忆和信念机制；(4) 推荐参数与用户行为的联合校准视角；(5) 统一的 YAML 配置中枢。

8.2 MOSS vs SALM（分层 Prompt 代表）

MOSS（本工作）

  • 画像数据结构本身分层（9 字段 vs 3 字段），不同层级信息粒度不同
  • Rogers 传播学理论提供分层依据
  • 离线 ABM 校准中也有 TIER_WEIGHT 影响力分层（与在线 Prompt 侧分层一致）
  • 离线校准→在线注入的完整闭环
  • 仅支持文本级社交交互
  • 无形式化人格稳定性保证

SALM (2025.05)

  • Prompt 文本分层共享（全局/群体/个体层），数据结构不变
  • 节省 73% token
  • 4000+ 轮次稳定模拟
  • 人格稳定性形式化数学边界
  • 注意力记忆系统（80% 缓存命中率）
  • 无参数校准功能

关键区分：SALM 的核心贡献是"如何用更少的 token 模拟更长的轮次"，MOSS 的核心贡献是"如何保证离线校准与在线部署的参数一致性 + 如何用传播学理论指导用户分层"。两者是不同的学术贡献方向，不直接竞争。SALM 的形式化人格稳定性分析是 MOSS 可以借鉴的方法。

MOSS（本工作）

  • 信念更新：Soft Backfire（可反向强化，建模逆火效应）
  • 参数校准：向量化 ABM + Dirichlet-EM 自动搜索
  • 校准注入：自动注入在线推荐系统
  • 用户画像：五阶段 LLM 流水线 + Rogers 理论分层
  • 离线 ABM 引擎为向量化实现（校准用，一步更新全部 Agent 状态）

FDE-LLM (Nature Sci Reports 2025)

  • 信念更新：SIR（Susceptible-Infectious-Recovered，感染-恢复）
  • 参数校准：无自动化校准（依赖 LLM 角色扮演）
  • 校准注入：不涉及推荐系统
  • 用户画像：LLM 角色扮演（非结构化）
  • 在 4 个真实微博数据集上验证，R² > 0.93

8.4 MOSS vs OASIS / Light Society（规模化路线）

OASIS (2024, 百万 Agent) 和 Light Society (2025, 十亿 Agent) 代表了"以规模换涌现"的路线—— 通过将模拟推向极限规模来观察社会现象的自然涌现。这条路线在验证宏观社会规律（极化、羊群效应、信任博弈）方面非常强大。

MOSS 的差异化：MOSS 不走纯规模化路线，而是走"精准画像 + 闭环校准"的路线—— 目标是使有限数量（1500+）的 Agent 在行为上足够逼真，且其行为由真实数据校准后的参数驱动。 两条路线互补而非竞争——未来 MOSS 的分层画像体系可以为大规模模拟提供更精准的用户原型。

9. 传播学与认知科学理论融合

9.1 为什么需要多理论融合

当前 MOSS 的传播学支撑仅有 Rogers 创新扩散理论。虽然 Rogers 的 5 级分类为用户分层提供了优雅的工程框架， 但社交媒体的信息传播机制远比"创新扩散"复杂——涉及多步级联、平台算法放大、认知失调、群体极化、沉默螺旋等多个维度。 单一理论无法覆盖 MOSS 的全部设计决策（Soft Backfire、TIER_WEIGHT、Per-Batch Norm、Feed 排序等），需要多理论融合支撑。

9.2 信息扩散：多步多主体扩散模型（Serafino et al., 2024 JSTAT）

核心发现：基于 Twitter/X 真实数据，信息传播可达 9 步级联，挑战了经典两级传播论（Katz & Lazarsfeld 1955）。 识别出三类新型传播主体：Influencers（社交媒体原生意见领袖）、Opinion-leading Influencers（传统意见领袖的社交媒体化）、Adopters（跳过所有中介直接从源头获取信息的用户，约 5%）。

对 MOSS 的启示：Rogers 的线性扩散（L5→L4→L3→L2→L1）过于简化。多步多主体模型可以解释为什么在 ABM 仿真中 L3 用户有时比 L4 更早传播某条内容——因为 Adopter 类型的用户可能跳级直接从 L5 获取信息。这为 ABM 中的非逐级传播概率提供了理论依据。

9.3 群体极化：多层复用网络模型（Chueca Del Cerro, 2024, Applied Network Science）

核心贡献：首次将沉默螺旋理论（Noelle-Neumann 1974）形式化为可计算的阈值机制—— Agent 在感知自己是局部网络少数派时压抑异见表达。整合线下小世界网络（Watts-Strogatz）+ 线上无标度网络（Barabási-Albert）为双层复用网络。 关键发现：同质性社交网络 + 过滤气泡算法 → 最强极化效果。单独任一个因素都不足以产生极端极化。

对 MOSS 的启示：ABM 种群合成为什么要在 stance 维度上做高斯噪声抖动——因为同质性（homophily）是极化形成的必要条件。Soft Backfire 可以结合沉默螺旋——当用户感知自己是少数派时，不仅"不表达"，还可能"反向强化"（Backfire）。

9.4 优先用户与信息茧房锐化（iScience, 2024）

核心发现：少数极端意识形态的"优先/认证用户"（被推荐算法 boost）可触发从共识到极化的相变。 提出了新型同质性双峰系数（BC_hom）指标来量化信息茧房的形成程度。

对 MOSS 的启示：为 TIER_WEIGHT 机制提供理论支撑——L5 (2.0×)、L4 (1.5×) 的高权重不仅因为"影响力大"， 更因为推荐算法的放大效应使高 tier 用户获得了不成比例的传播优势。BC_hom 可作为新的宏观评估指标。

9.5 意见再生数 R₀ 框架（Brooks & Porter, 2024）

核心贡献：将流行病学 SIR 模型引入意见动力学，定义"意见再生数"——类 R₀ 的临界阈值。 高于阈值则内容"走红"，低于阈值则消亡。在阈值附近，传播树可以"更深但更窄"。

对 MOSS 的启示：可直接补充 Soft Backfire 机制。R₀ 框架解释宏观传播爆发条件， Soft Backfire 解释微观个体在接触对立意见后的认知反应。两者互补，可用于解释为什么某些内容在模拟中"火了"而另一些没有。

9.6 认知失调驱动极化（Kovács et al., 2024-2025, Scientific Reports）NEW

核心发现：Agent 被赋予内部信念网络（而非标量意见），驱动力是维持信念一致性、避免认知失调。 即使所有 Agent 从完全相同信念出发，认知失调避免机制也会自发产生碎片化和极化。 逆火效应（排斥性交互）从认知失调中自然涌现，无需单独规则。

对 MOSS 的启示：为 Soft Backfire 提供了更深层的理论解释——逆火效应不是需要单独添加的行为规则，而是认知失调避免的自然产物。未来可以将 Soft Backfire 重新表述为认知失调驱动的结果，而非独立机制。

9.7 建议的理论融合框架

核心策略：构建"一个主理论 + 四个支撑理论"的融合框架，为 MOSS 的每个核心设计决策提供理论依据。

主理论（用户分层）：Rogers 创新扩散 5 级 — 为分层提供传播学理论基础，P84 阈值对应 Innovators+Early Adopters ≈ 16%，TIER_WEIGHT 反映不同层级在扩散过程中的影响力差异。

支撑理论 1（信息传播机制）：多步多主体扩散模型 (Serafino 2024) — 解释 ABM 中的非逐级传播、跨级感染，挑战线性扩散假设。

支撑理论 2（信念更新机制）：认知失调避免理论 (Kovács 2024-2025) + 逆火效应 (Nyhan & Reifler 2010) — 解释 Soft Backfire 为什么发生，意见在什么条件下极化。

支撑理论 3（群体极化条件）：多层复用网络 (Chueca Del Cerro 2024) + 优先用户效应 (iScience 2024) — 解释为什么同质性合成 + TIER_WEIGHT 加权会放大极化。

支撑理论 4（宏观传播阈值）：意见再生数 R₀ (Brooks & Porter 2024) — 解释什么条件下内容会病毒式传播或消亡。

论文中的表述示例："本文以 Rogers 创新扩散理论为主要组织框架，构建 5 级用户分层体系。在信息传播机制上，参考 Serafino 等 (2024) 的多步多主体扩散模型，设计了非逐级的跨层感染概率；在信念更新方面，融合 Kovács 等 (2024) 的认知失调驱动极化理论与 Nyhan & Reifler (2010) 的逆火效应发现，提出 Soft Backfire 机制；在宏观传播条件分析中，引入 Brooks & Porter (2024) 的意见再生数 R₀ 框架……"

11.4 关于"原来创新点被挑战"的说明

原创新点表述："使用高低模型配合省 token——L4-L5 用大模型，L1-L3 用小模型，比人家省 token"

为什么这个表述需要升级：
1. OASIS (2024) 已用 Llama3-8B 本地跑百万 Agent——证明了"用小模型本地运行"并非独特优势
2. SALM (2025.05) 通过分层 Prompt 架构节省 73% token——"省 token"已有更精细的独立技术方案
3. 教师判断："小模型用户仿真节省 token 技术方案不是最优的。人家有了更好的模型，可以直接本地"
4. 但关键不在于此：如果将 MOSS 的分层策略仅表述为"省 token"，就完全丢失了它与 HiSim 等 Hybrid 框架的本质区别——HiSim 的 Ordinary User 是数学公式驱动的 ABM（没有语言行为），而 MOSS 的 L1-L3 虽然用小模型，但仍然是具有语言生成和推理能力的 LLM Agent。

升级后的学术叙事：
MOSS 提出了"全 LLM Agent + 分层模型驱动"范式——区别于 HiSim/FDE-LLM 的"Core LLM + Ordinary ABM"混合路线。
在 MOSS 中，ABM 的角色被严格限定为离线推荐参数反推引擎（向量化 ABM + Dirichlet-EM 校准）；
在线模拟阶段，所有用户均为 LLM Agent，通过 Rogers 创新扩散理论指导模型分层：
  • L4-L5（Innovators + Early Adopters, 前 16%）：大模型驱动 + 9 字段详细画像 → 高保真度
  • L1-L3（Early/Late Majority + Laggards, 后 84%）：小模型驱动 + 3 字段简化画像 + 预设行为模板 → 经济性
这一设计的学术贡献不在于"省钱"，而在于：(1) 所有用户保持语言级行为逼真度（与 ABM 代理有本质区别）；(2) Rogers 理论为分层比例提供了传播学依据；(3) "大模型保真 + 小模型保量"的策略使得"全 LLM Agent"路线在成本上可行。
