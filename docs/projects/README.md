## 当前版本边界

本目录描述的是仓库当前 `main` 分支的可见实现。离线画像 → 参数校准 → 在线社交模拟的闭环、`simple` 模式全链路、记忆检索时间衰减、嵌入模型统一、大小模型分层等主线能力已完成，并通过 `test.py` 49 项验证脚本覆盖；尚未收口的事项（Agent 动作幂等、进程生命周期收尾等）统一标注为待实现，不表述为已完成能力。
