# 用户画像

> 毕业设计项目：MOSS Web 社交媒体舆情模拟推演平台
> 完成人：张艺鹏（个人完成）
> 文档范围：从原始用户/帖子表格到结构化 Agent 画像的离线流水线，以及画像模式与 Rogers 分层。

## 1. 功能目标

把用户资料与历史发帖转成可直接驱动 Agent 的结构化画像：长期兴趣、价值立场、表达风格、行为偏好、社交角色与模拟初始状态，为在线推演提供“完整画像种子用户”。

## 2. 输入格式

入口为 `analysis.run_analysis portrait`，读取 `user.xlsx` 与 `post.xlsx`（也可用 CSV，文件名可用 `--user-file`/`--post-file` 覆盖）。

**用户表必需列**：用户名、昵称、简介、性别、地域、关注、粉丝、收藏、创建时间戳（可选：源用户名、用户地址、头像链接）。

**帖子表必需列**：用户名、发文内容、发布时间、发布时间戳、发文类型（可选：点赞数、评论数、转发数、帖子ID）。

## 3. 五阶段 LLM 流水线

`UserPortraitGenerator.run_pipeline` 对每个用户执行 5 个阶段（[user_portrait_generator.py](/Users/zhangyipeng/Documents/moss_web/analysis/user_portrait_generator.py)），每阶段独立重试（最多 3 次）：

| 阶段 | 产物 | 说明 |
|---|---|---|
| A 证据抽取 | `EvidencePack` | 帖子分块并行抽取主题、风格、行为、价值观信号与不确定项 |
| B 稳定画像 | `StableProfile` | 长期兴趣、价值立场（value_anchors）、表达风格、社交角色、人口学 |
| C 行为画像 | `BehaviorProfile` | 活跃模式、动作偏好概率、互动偏好、内容偏好、触发规则 |
| D Agent 画像 | `AgentProfile` | 压成单一主人格摘要：身份/兴趣/价值/风格/行为/互动 + 表达/行动/回避规则 |
| E 模拟初始状态 | `SimulationInit` | 情绪、目标、关注话题、立场摘要、注意力目标 |

证据选择按四类排序取并集：最近（recent）、高影响（high_impact）、风格代表（style_representative）、类型代表（type_representative），最多 `max_posts_per_chunk × max_chunks`（默认 120 条）条。

## 4. 统计画像与影响力

`analyze_stats` 从用户资料和帖子计算 `UserStats`：粉丝/关注/收藏、发帖数、原创/评论/转发/引用占比、活跃时段、平均互动、帖子影响力（点赞×1 + 评论×2 + 转发×3 加权）与账户影响力（粉丝×0.5 + 帖子影响力×0.3 + 活跃×0.2）。

## 5. 批量模式与 Rogers 分层

批量模式（`--batch`）分三阶段：先读全表建索引、预计算所有用户的 `account_influence`（不调 LLM）；再用 **P84 单阈值**切分为 L4/L5（Rogers 5 级框架，仅含 Early Adopters + Innovators）；最后调 LLM 生成画像并注入 `influence_tier`。已存在画像的用户跳过生成、原地更新 tier；失败用户写入 `failed_users.json`。`retier` 子命令可对已有画像目录重新按 P84 分级回写。

## 6. 画像模式与 tier（两类用户）

在线推演需要两类用户：由历史数据生成完整结构化画像的**核心用户**，与补足总体分布的低活跃**预设用户**。分层由两个正交维度组成：

- **画像模式 `profile_mode`**（决定“用什么画像驱动”）：
  - `default`：5 阶段生成的完整结构化画像；
  - `custom`：自定义模板 + 内联/文件画像；
  - `simple`：仅 bio + 按 tier 的行为预设（`SIMPLE_USER_TEMPLATE`），供低层级预设用户低成本驱动。
- **层级 `tier`（1–5，Rogers 创新扩散）**（决定“传多远 / 多活跃”）：
  - 作为行为与影响力参数贯穿全链路：`TIER_WEIGHT`（热度打分作者加权）、`simulation.p_online`（ABM 在线概率）、`TIER_BEHAVIOR`（simple 用户活跃度描述）。

`AgentConfig` 校验 `profile_mode` 取值与 `tier` 范围（[experiment_config.py](/Users/zhangyipeng/Documents/moss_web/core/experiment_config.py)），`resolve_agent_payloads` 按模式解析画像并透传 `profile_mode`（[agent_profile_resolver.py](/Users/zhangyipeng/Documents/moss_web/core/agent_profile_resolver.py)）。批量画像按 P84 把真实用户切成 L4/L5（核心用户），L1–L3 由 `agents.csv` 里的 simple 预设行补充。

## 7. 输出画像结构

`SimulationUserProfile`（版本 `v3-single-persona`）包含：`stats`（统计画像）、`stable_profile`、`behavior_profile`、`agent_profile`、`simulation_init`、`evidence_meta`，以及供模板注入的扁平字段（identity/interest/value/style/behavior/interaction_summary、speaking/action/avoidance_rules_text）。单用户输出 `analysis_outputs/portraits/<user>.json`，批量输出到 `analysis_outputs/portraits/`。
