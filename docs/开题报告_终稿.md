**Design and Implementation of a Domain-Specific Social Network Simulation Platform**

## 二、研究背景与意义

### 2.1 研究背景

社交媒体已成为公众舆论形成、信息传播和社会运动组织的核心场域。然而，真实平台数据的不可获取性（商业黑箱、隐私限制）和在真实平台上进行对照实验的不可行性（伦理与监管约束），共同构成一个根本性挑战：**如何预测大规模用户群体对特定事件的响应？**

近年来，基于大语言模型（LLM）的Agent社交模拟迅速发展。自Park et al.（2023）在UIST上发表"Generative Agents"以来，该领域经历了从纯ABM到LLM Agent萌芽、到混合框架涌现（HiSim, ACL 2024; FDE-LLM, Nature Sci Rep 2025）、再到规模化与理论化（OASIS, 2024; SPARK, EMNLP 2025）四个阶段。

然而，现有系统在推荐机制方面存在两类问题。**第一类系统**（HiSim、SALM、SPARK、FDE-LLM等）根本未配备推荐/排序模块——Agent的信息获取依赖社交邻居传播或全局随机曝光，这与真实平台以推荐算法为核心的信息分发机制存在本质差异[^1]。**第二类系统**（OASIS、GGBond等）虽配备了推荐模块，但推荐参数来自人工预设，未从真实传播数据中推导。两类问题共同导致：**当推荐机制缺乏现实参照时，模拟涌现现象的可信度缺少实证基础。**

[^1]: OASIS论文（Yang et al., 2024, arXiv:2411.11581v5）的系统对比表在HiSim的RecSys列标注为×（无推荐系统），独立验证了这一事实。

### 2.2 核心问题

现有研究存在三条各自深入但缺乏交汇的研究线：

1. **LLM Agent行为模拟**（Generative Agents, HiSim, OASIS, SALM）——聚焦Agent行为逼真度，但多数系统未配备推荐机制或推荐机制简化；
2. **ABM舆论动力学**（FDE-LLM, Bounded Confidence, SIR模型）——聚焦态度的数学建模，但缺乏语言级行为细节；
3. **推荐系统参数校准**（RecSys领域）——聚焦算法参数优化，但几乎不与社交模拟交叉。

三者的脱节引出一个核心问题：若能从真实传播数据中反推推荐参数，并将其注入模拟系统，则模拟涌现现象将具备更强的实证参照。

### 2.3 研究意义

**理论意义**：（1）设计一种将离线ABM校准与在线Agent模拟串联的集成方法，使模拟中的信息分发逻辑由真实数据推导的参数驱动；（2）将90/9/1参与不平等法则作为用户分层框架，为模拟中的用户行为差异化提供实证依据；（3）通过消融实验揭示推荐参数校准对模拟保真度的作用机制。

**实践意义**：构建一个领域可配置的仿真平台，使研究者能够基于特定领域的原始社交数据，一站式完成用户画像生成、推荐参数反推和Agent模拟运行。平台的核心实用价值在于：同一套系统架构适配不同领域时，仅需替换输入数据即可自动产出该领域的推荐参数——这为传播学、政治学、市场营销等不同学科的研究者提供了可复用的实验基础设施。

**贡献边界**：本文不声称还原真实商业推荐算法的内部机制，目标是使模拟中的推荐参数源于真实传播数据的推导，而非研究者的主观设定。本文聚焦于传播动力学层面的复现验证，不声称能够预测个体用户的具体行为。

## 三、国内外研究现状

### 3.1 LLM Agent社交模拟

**Generative Agents**（Park et al., 2023, UIST）开创了LLM Agent社会模拟的先河，其"记忆-反思-计划"架构成为后续系统的基础模板。

**HiSim**（Mou et al., 2024, ACL Findings）将用户分为Core Users（约300，LLM驱动）和Ordinary Users（约700，ABM驱动），在Twitter数据集上验证。HiSim校准的是Ordinary Users的Bounded Confidence舆论动力学参数（影响阈值ε和邻居影响权重w），而非推荐系统参数——事实上HiSim未配备推荐/排序模块[^1]。该参数校准在纯ABM上进行后"迁移"至混合模型，存在分布偏移风险。

**FDE-LLM**（Yao et al., 2025, Nature Scientific Reports）提出CA + SIR + LLM三层混合框架。意见领袖由ChatGLM驱动，追随者由CA和SIR联合驱动。其在4个微博反转新闻事件上验证，DTW最优达0.3622，Pearson r达0.9653。关键消融发现：去掉CA约束后DTW恶化106%（0.3664→0.7530），证明数学约束对LLM Agent的必要性。但其CA/SIR参数（r=0.99, ε=0.5, λ=0.5, γ=0.9）均为Grid Search预设，无自动化校准。

**OASIS**（Yang et al., 2024）实现百万级Agent模拟，配备推荐模块——X场景用TwHIN-BERT兴趣匹配+新鲜度排序，Reddit场景用hot-score公式——但推荐参数均为预设值。

**SALM**（Koley, 2025）提出分层Prompt架构，节省73% token。关键贡献包括注意力记忆系统和人格稳定性形式化保证。不涉及推荐参数校准。

**SPARK**（Zhang et al., 2025, EMNLP）是首个LLM多智能体话题-立场共演化模拟框架。关键发现：立场变化与话题演化双向强化（Pearson r = 0.88）。未配备推荐模块。

**GGBond**（Zhong et al., 2025）提出五层认知架构结合多层社会图，构建推荐-社交联合模拟闭环。推荐使用标准MF/MultVAE/LightGCN算法，参数从预设值出发。

**Tomašević et al.（2025）**在Reddit-like论坛上进行30次独立30天模拟，发现LLM Agent在用户活跃度等维度上复现真实规律（99% CI重叠），但在评论长度分布和毒性分布上存在系统性偏差。

### 3.2 推荐系统参数校准

**MTRec**（Zhao et al., 2025, NeurIPS）提出分布逆强化学习从用户隐式反馈中反推满意度奖励函数，方法论思路与本文的ABM+EM校准一致，但目标不同——MTRec面向推荐性能优化，本文面向模拟可信度提升。

**Beyond Imitation**（Li et al., 2025）证明了监督微调与逆Q-Learning的形式等价性，为"从传播结果反推推荐权重"提供了数学基础。

### 3.3 用户画像生成

**两阶段LLM用户画像**（Rahimzadeh et al., 2025, ICWSM Workshop）提出半监督过滤+双输出流水线，在Twitter数据上超越SOTA 9.8%。

**TWICE**（Jin et al., 2026）提出个性化用户推文行为模拟框架，考虑了心理状态波动和语言风格漂移等动态特征。

**Population-Aligned Persona Generation**（Hu et al., 2025）提出重要性采样将LLM生成画像与心理测量分布对齐，降低群体偏差。

### 3.4 现有研究空白

综合以上文献，**在所有现有LLM Agent社交模拟系统中，尚无任何一个从真实传播数据中校准推荐参数**：

| 系统               | 配备推荐系统？ | 推荐参数来源             | 校准了什么？                |
| ------------------ | :------------: | ------------------------ | --------------------------- |
| HiSim (ACL 2024)   |     ❌ 无      | —                        | ABM舆论动力学参数（ε, w）   |
| FDE-LLM (2025)     |     ❌ 无      | —                        | CA/SIR参数为Grid Search预设 |
| SALM (2025)        |     ❌ 无      | —                        | 无参数校准                  |
| SPARK (EMNLP 2025) |     ❌ 无      | —                        | 无参数校准                  |
| OASIS (2024)       |     ✅ 有      | 人工预设                 | 无参数校准                  |
| GGBond (2025)      |     ✅ 有      | 人工预设                 | 无参数校准                  |
| **本文**           |   **✅ 有**    | **ABM+EM从真实数据反推** | **推荐四维权重 + 衰减系数** |

这一空白构成了本研究的核心切入点。

## 四、研究内容与方法

### 4.1 研究目标

设计与实现一个**面向特定领域的社交网络仿真平台**。该平台的核心特征是**领域可配置性**——系统本身不绑定任何特定数据领域，而是通过从目标领域的真实传播数据中反推推荐参数，实现对该领域信息分发机制的适配。不同领域的传播数据将产生不同的校准参数，进而驱动差异化的模拟行为。

三章核心内容为：

- **第三章**：特定领域数据集构建 + 用户画像自动生成（数据基础）
- **第四章**：ABM+EM推荐参数反推（平台核心——不同领域产出不同参数）
- **第五章**：LLM+ABM混合模拟平台与保真度验证（平台运行与评估）

### 4.2 第三章：数据集构建与用户画像生成

#### 4.2.1 数据集构建

采用动态网络测绘与滚雪球抽样方法，从战略传播、政治传播、文化传播、经济传播4大情景的57个热点事件出发，采集X平台（原Twitter）数据。引入多因子特征过滤（粉丝数、参与次数、行为特征）和偏差阈值校验，区分活跃账号与休眠账号。最终构建包含约258.6万条信息、近50万活跃节点的账号池。

基于X平台2024年官方数据（发文量3.6亿、独立访问近50亿、发文浏览比1:13.8），利用90/9/1法则推算：泛在受众约2400万，过滤机器人/异常行为后，核心关注受众600万-800万。

对20个热点案例的复杂网络分析验证数据符合无标度特性（幂律指数2.5-2.6）、小世界效应（平均最短路径2.3-2.4）和回声室效应（聚类系数0.28-0.29），证明数据集的拓扑真实性。

#### 4.2.2 用户画像生成

采用五阶段LLM流水线生成用户画像：

| 阶段 | 内容                                                           | LLM调用 |
| ---- | -------------------------------------------------------------- | :-----: |
| A    | 统计特征计算（活跃度、影响力、情感倾向等~25个指标）            |   否    |
| B    | 证据帖选取（5-10条高代表性帖子）                               |   否    |
| C    | 稳定画像生成（人口统计推断、表达风格、价值立场锚点、社会角色） |   是    |
| D    | 行为画像生成（活跃模式、互动偏好、内容偏好、触发规则）         |   是    |
| E    | Agent画像压缩 + 模拟初始状态                                   |   是    |

#### 4.2.3 用户分层：90/9/1法则

以90/9/1参与不平等法则为分层框架：

|    层级     | 比例 | 角色                 | 画像策略             | 模拟引擎           |
| :---------: | :--: | -------------------- | -------------------- | ------------------ |
| C（创作者） | ~1%  | 发原创帖、评论、转发 | 五阶段LLM详细画像    | GPT-4              |
| B（互动者） | ~9%  | 点赞、转发、模板评论 | 简化画像（3字段）    | 8B小模型 + ABM门控 |
| A（浏览者） | ~90% | 浏览为主，极少点赞   | 无画像（仅tier+bio） | 纯ABM评分          |

与Rogers创新扩散理论的关系：90/9/1描述参与强度分布（幂律），Rogers描述采纳时间分布（正态），两者正交但互补。90/9/1与本文的模拟问题域（内容消费行为）直接匹配，故作为主要分层框架。

### 4.3 第四章：基于ABM+EM的推荐参数反推

#### 4.3.1 语义处理与种群合成

**语义处理**：

- Kernel PCA（RBF kernel）将多维价值立场投影至一维立场轴
- SentenceTransformer（BAAI/bge-m3）计算用户-内容兴趣匹配度

**种群合成**：

- 种子用户按90/9/1比例扩量（target_size = len(seeds) / 0.1）
- 精英保留 + Zipf影响力分布 + 高斯噪声合成大众用户
- 合成质量通过KS统计量验证

#### 4.3.2 向量化ABM引擎

**四维评分公式**：

$$score = w_i \cdot \text{norm}(interest) + w_{pop} \cdot \text{norm}(pop \times tier\_weight) + w_{time} \cdot \text{norm}(e^{-\lambda \cdot \Delta t}) + w_{rand} \cdot \text{norm}(random)$$

其中 $\sum w = 1$，norm(·)为Per-Batch Min-Max归一化。

- Per-Batch Min-Max消弭维度量纲差异，保证权重可解释和离线-在线可迁移
- 指数时间衰减 $e^{-\lambda \cdot \Delta t}$，λ纳入Optuna搜索
- Soft Backfire信念更新模拟逆火效应

#### 4.3.3 EM校准引擎

**E步**：Optuna（20次试验×5次仿真）校准每条代表性内容的传播基础概率 $p_{base}$。

**M步**：Dirichlet分布约束下搜索全局权重（w_i, w_pop, w_time, w_rand）+ decay_lambda。

收敛判据：连续两轮最优损失相对变化 < 1%。

#### 4.3.4 参数可辨识性与搜索策略

**参数可辨识性分析**：

1. 合成数据测试：用已知参数生成传播数据，注入不同噪声水平，测试恢复精度
2. Morris敏感性分析：识别对传播结果影响最大的参数维度
3. VIF共线性诊断

**搜索策略对比**：Grid Search / Random Search / Optuna TPE / EM（本系统），在固定计算预算下比较收敛速度和最优损失。

#### 4.3.5 跨领域参数对比

本平台的一个重要特性是**领域可配置性**——同一套校准流程应用于不同领域的数据，将产出不同的推荐参数。拟选取两个不同领域（如政治传播 vs 娱乐传播，或不同话题类型）的数据集，分别运行ABM+EM校准，对比两组参数在各维度上的差异。预期发现：不同领域的推荐权重分布存在系统性差异（例如政治领域可能更偏重兴趣/立场匹配w_i，娱乐领域可能更偏重热度w_pop）。这一对比不仅验证了平台的领域适配能力，也证明了"推荐参数必须从真实数据反推而非人工预设"的必要性——不存在一组普适的推荐参数。

#### 4.3.6 输出

校准完成后自动生成 `calibration_profile.yaml`，包含校准权重和在线模拟全部参数。这是离线到在线的唯一数据接口。跨领域对比时，每个领域各自生成独立的配置文件。

### 4.4 第五章：LLM+ABM混合模拟平台

#### 4.4.1 混合架构总览

模拟规模为1000个用户，按90/9/1比例分配：

| 层级 | 人数 | 引擎         | 画像           | 动作集                   | 文本生成 |
| :--: | :--: | ------------ | -------------- | ------------------------ | :------: |
|  C   |  10  | GPT-4 Agent  | 详细（9字段）  | 发帖/评论/点赞/转发/引用 |   LLM    |
|  B   |  90  | 8B + ABM门控 | 简化（3字段）  | 点赞/转发/模板评论       | 8B小模型 |
|  A   | 900  | ABM评分      | 无（tier+bio） | 浏览/极少点赞            |    无    |

其中A层态度变化的唯一通道：**SocialRecSys Feed（校准参数排序）→ 看到的内容 → 内容态度影响自身态度**。无邻居传播，无独立CA机制，保证因果链清晰可归因。

#### 4.4.2 C层：LLM Agent决策引擎

每个C层Agent通过LangChain决策循环，每轮：获取Feed → 记忆检索 → LLM决策 → 执行社交动作 → 更新记忆。配备三层记忆系统（短期记忆3轮、事件记忆50条、Agent状态）和Ebbinghaus遗忘曲线驱动的乘法检索评分。

#### 4.4.3 B层：8B小模型 + ABM评分门控

B层用户的"要不要互动"由第四章校准的ABM评分公式决定，8B小模型仅负责"怎么互动"的文本生成：

```
1. Feed排序：SocialRecSys用校准参数排序
2. ABM评分门控：对每条Feed计算四维评分 → score > θ_B则触发互动
3. 8B文本生成：决定"点赞/转发"还是"模板评论"
```

8B模型零API成本（本地Ollama部署），B层90人每轮做ABM评分筛选后，实际触发8B推理的次数远小于90。

#### 4.4.4 A层：纯ABM内容消费引擎

A层900人完全不调用LLM。行为由第四章校准参数决定：

```
每轮：
  Feed排序（校准参数）
  → 对每条Feed计算四维评分
  → score > θ_A（高阈值）→ 点赞（概率性）
  → 更新用户态度值：O_new = O_old + lr * (content_stance - O_old)，仅当score > θ_A
```

A层的态度变化只受一个因素影响：校准参数决定的Feed排序。这保证了第四章的校准参数到第五章的模拟结果之间存在**直接的因果链条**。

#### 4.4.5 模拟保真度评估

采用FDE-LLM论文的两项指标：

1. **DTW（Dynamic Time Warping）**：衡量模拟态度序列与真实态度序列的时序相似度，越小越好
2. **Pearson r**：衡量线性相关性，越接近1越好

评估对象：A层900人的态度均值曲线 vs 真实数据中"沉默大多数"的态度时序。

#### 4.4.6 消融实验

| 消融变量     | 实验条件   | 对照条件           | 预期检测的因果效应                  |
| ------------ | ---------- | ------------------ | ----------------------------------- |
| 推荐参数来源 | 校准参数   | 均匀权重（0.25×4） | 校准对态度复现的提升                |
| B层引擎      | 8B+ABM门控 | B层纯ABM           | 小模型文本生成对B层行为自然度的贡献 |
| A层态度更新  | 有态度更新 | 无态度更新（静态） | A层态度变化机制的必要性             |

**实验假设**：校准参数条件下DTW显著低于均匀权重，Pearson r显著高于均匀权重。B层使用8B小模型时，B层互动文本自然度优于纯模板。

**Step 1 — 数据集构建 + 画像生成**

```

```

**Step 2 — 推荐参数反推**

```

→ 参数可辨识性验证 → 搜索策略对比 → 跨领域参数对比
→ 输出领域相关的 calibration_profile.yaml
```

```
main.py --config calibration_profile.yaml
→ SocialRecSys.configure() 注入校准参数
→ C10 (GPT-4 Agent) + B90 (8B+ABM门控) + A900 (纯ABM)
→ DTW + Pearson r 评估
→ 消融实验
```
