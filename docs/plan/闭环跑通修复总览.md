## 背景

对照开题报告《融合推荐机制校准的社交仿真平台设计与实现》的端到端闭环：

```
user/post.xlsx → 画像生成 → portraits/*.json
portraits/*.json + 内容观测.xlsx → ABM/EM 校准 → calibration_profile.yaml
calibration_profile.yaml → main.py → 注入 → 在线仿真 → runs/<ID>/
```

流程设计成立、方法有文献依据。经三层代码 review（2026-08-15），大部分闭环修复**已实现**，剩余待办另见 [[待实现工作方案]]，研究定位见 [[研究总览_创新点与验证]]。

## 已定决策

- **时间基准**：每步 1 小时（`time_scale: 3600`，`rounds: 24` → 总跨度 24 小时）。`hours_per_step = time_scale/3600` 单一真值源，dt 统一到小时后 **decay_lambda 与步长解耦、改 time_scale 无需重算 λ**。
- **可辨识性**：数据无时序，w_time/decay_lambda 弱辨识。**代码保留四维校准，论文声明其为弱辨识参数、仅作正则、不作校准结论汇报**。
- **验证方法**：无时间序列 → DTW 轨迹拟合作废，改 Pattern-Oriented Modeling 多弱模式（分布 KS + 秩相关 + 留出 + 多次重复 CI + 消融）。
