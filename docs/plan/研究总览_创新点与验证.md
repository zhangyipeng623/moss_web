# 研究总览：创新点、后续工作与验证方法

> 本文是毕设《融合推荐机制校准的社交仿真平台设计与实现》的研究锚点，固化几轮讨论的关键结论。
> **核心数据约束**：观测数据是**横截面的最终传播量**（每条内容一个转发/观看总数），**无时间序列**。此约束决定创新点定位与验证方法。

## 一、创新点

**核心：真实传播数据驱动的可解释推荐机制校准 + 大小模型分层社交仿真**

### 三个可辩护的创新点

1. **推荐机制作为内生变量，且用真实数据校准其参数**
   区别于 OASIS/GGBond（推荐参数人工/经验设定）、PolicySim（政策优化非机制校准）。把推荐曝光抽象为兴趣/热度/时效/随机四个**可解释维度**（为什么要选这四个维度，解释清楚。），用真实传播观测反推权重。这是与已有工作最实的差异。

2. **大模型核心用户 + 小模型/规则普通用户的分层混合仿真**
   L4/L5 走真实数据画像 + 大模型；L1-L3 走 tier 预设行为库。对标 HiSim 分层思想，落到画像生成成本分层。
   怎么证明这一块更优。（就是全是大模型效果好，但是大小模型效果差不多，成本很少）

3. **离线校准 → 在线仿真的统一配置闭环**
   `calibration_profile.yaml` 单一配置中枢，保证离线 ABM 与在线推荐的参数/公式一致（共享 `core/scoring.py` 打分模块）。

### ⚠️ 必须诚实收窄的边界（防答辩被问穿，对应 017/031 号文献"别过度声明"）

- **不是逆强化学习**：代码是前向仿真拟合（simulation-based calibration），不是 IRL。MTRec(022)/Beyond Imitation(023) 只能作为 related work 的方法启发，不能声称自己做了 IRL。
- **不是传播动力学校准**：数据无时间序列，创新点聚焦"**稳态传播规模的分布与排序**"，而非"传播过程/时间演化"。
- **时间维度弱辨识**：见下方"可辨识性"。

## 二、后续工作（按优先级）

### 第一梯队——救活校准方法（不做则校准无意义）
1. Optuna 真正搜索四维权重（原为随机抽 Dirichlet）
2. ABM 补齐四维 Min-Max 归一化（原只做 interest/rand 两维）
3. tier 打通到仿真（原全默认 L4）
4. **可辨识性处理（已决策：保留四维 + 论文声明）**：数据无时间信息 → `w_time`/`decay_lambda` **不可从数据辨识**。**代码保留四维校准不改**，但论文/答辩中明确声明 `w_time`/`decay_lambda` 为**弱辨识参数，仅作正则项，不作为已校准结论汇报**。这是诚实的范围声明，也是本课题一个值得写入的"可辨识性分析"点。（备选方案"固定 decay_lambda 为先验、只搜三维"更干净，但当前不采用。）

## 三、验证方法（无时间序列版）

放弃 DTW 轨迹拟合（数据不支持），改为**分布 + 排序 + 留出**组合验证。方法论定位：**Pattern-Oriented Modeling（多个弱模式同时匹配）**，而非单一终值拟合——避免"停摆时钟"问题（仿真经错误路径到达正确终点）。

| 方法 | 验证什么 | 文献依据 |
|---|---|---|
| **留出验证 70/30** | 校准集反推、验证集测试，防过拟合 | Larooij & Törnberg (2025) |
| **KS 检验 + 分布形状** | 仿真传播量分布 vs 真实（重尾/幂律能否复现） | Operational Validation (015) |
| **Spearman 秩相关** | 模型能否分辨"哪些内容会火" | POM / JASSS 20/2/11 |
| **N≥30 重复 + 置信区间 + Cohen's d** | 统计等价，不靠单次 | Operational Validation (015) |
| **消融实验**（逐维去权重看退化） | 证明四维各自有贡献 | EASE (018) |
| **鲁棒性审计**（扰动种子/画像措辞） | 权重结论是否稳定 | TRAILS (016) |

### 做不了的（诚实划掉）
- ❌ DTW 轨迹对齐、峰值时间/大小（ΔWhen/ΔMax）、传播速度/爆发时刻——均需时间序列。

### 论文范围声明（建议原文写入方法章节）
> 本课题观测数据为内容级最终传播量的横截面数据，因此校准与验证聚焦于**稳态传播规模的分布特征与内容间排序一致性**，而非传播动力学轨迹。时间衰减参数因数据缺乏时间信息而不可辨识，作为先验常数处理。
