# ABM Agent 影响力机制分析：HiSim vs FDE-LLM vs MOSS

## 核心问题

HiSim 和 FDE-LLM 中的 ABM Agent（非 LLM 驱动的普通用户）不写帖子、不评论、不点赞，那它们如何对社交平台产生影响？

## 答案概要

ABM Agent 的"影响力"体现在**宏观舆论分布层面**，而非个体行为层面。它们代表传播学中"沉默的大多数"——不产生可见内容，但集体意见构成了社会舆论的底色。

---

## 1. 理论基础：90-9-1 法则

传播学中的经典规律：

| 角色 | 占比 | 行为 | 对应模拟方式 |
|------|------|------|-------------|
| 内容创造者 | 1% | 发帖、发布观点 | LLM Core Agents / Opinion Leaders |
| 互动者 | 9% | 评论、点赞、转发 | — |
| 沉默大多数 | 90% | 只阅读、形成观点、不发言 | ABM Agents (数学函数驱动) |

ABM Agent 模拟的就是这 90%。舆论研究真正关心的不是大 V 说了什么，而是**沉默大多数的态度分布如何随时间漂移**。

---

## 2. HiSim：Ordinary User 的 ABM 机制

### 2.1 Bounded Confidence Model（有界信任模型）

每个 Agent 有一个数字化的态度值 O ∈ [-1, +1]，更新规则：

- 当 Agent A 看到 Agent B 的态度时，先算距离：|O_A - O_B|
- 如果距离 ≤ 阈值 ε（如 0.5），A 被 B 影响
- 如果距离 > ε，则无视

HK 模型更新公式：

```
O_A_new = O_A + w * (O_B - O_A)
```

w 为影响权重，本质是数字的加减运算，Agent 不发表任何文字内容。

### 2.2 Social Judgement Theory（社会判断理论）

比 Bounded Confidence 更细粒度：

- 将对方意见分为**接受区 / 中立区 / 拒绝区**
- 处于拒绝区的意见产生**反向效果**——对方越说，我越往反方向走
- 解释了"越辩越极化"的现象

### 2.3 关键特征

- 驱动方式：纯数学公式（Bounded Confidence）
- 行为类型：数字更新，无文本输出
- 态度粒度：连续值 [-1, +1]
- 能生成内容吗：❌ 不能
- 能响应具体事件吗：❌ 只能更新态度数值

---

## 3. FDE-LLM：Follower 的 CA + SIR 机制

FDE-LLM 把普通用户叫"Follower"（追随者），采用两套数学模型联合驱动。

### 3.1 Cellular Automata（元胞自动机）

```
O_i^{t+1} = r · O_i^t
            + w · Σ(O_j^t - O_i^t) · r · |O_j^t|
              · I(|O_j^t - O_i^t| ≤ ε)
```

| 参数 | 含义 | 典型值 |
|------|------|--------|
| r | 态度保持系数 | 0.99（Agent 很固执） |
| ε | 影响阈值 | 0.5（距离 > 0.5 则无视） |
| w | 邻居影响权重 | — |

三个约束机制：

1. **态度保持（r=0.99）**：Agent 每轮只愿意改变一点点，模拟认知惯性
2. **阈值过滤（ε=0.5）**：态度差距太大的人直接忽略，不产生任何影响
3. **非线性影响**：极端态度的人（|O| 接近 1）影响力更大（通过 |O_j^t| 加权）

### 3.2 SIR 流行病模型

```
O_final = O_CA · e^(-λ · |O|) · I(random < γ)
```

| 参数 | 含义 | 典型值 |
|------|------|--------|
| λ | 衰减系数 | 0.5 |
| γ | 恢复概率 | 0.9 |

每轮有 90% 的概率态度向中性衰减——模拟"吃瓜群众看累了、不关心了"，解释为什么舆论热度会自然消退。

### 3.3 Opinion Leader 的 LLM + CA 融合

FDE-LLM 中约 10% 的意见领袖是 LLM 驱动的，但做了一个特殊设计：

```
O_final = α · O_CA + (1-α) · O_LLM
```

- LLM 输出离散态度（-1 / 0 / +1），CA 输出连续态度值
- α 是融合系数，CA 的作用是**约束 LLM**，防止它过度反应
- 论文消融实验：去掉 CA 约束后，DTW 误差从 **0.3664 → 0.7530**（恶化 106%）

### 3.4 关键特征

- 驱动方式：CA + SIR 联合公式
- 行为类型：数字更新，无文本输出
- 态度粒度：连续值 [-1, +1]
- 能生成内容吗：❌ 不能
- 能响应具体事件吗：❌ 只能更新态度数值

## 4. 影响力如何体现？（无动作 ≠ 无影响）

### 4.1 影响机制对比

| 影响层面 | HiSim (Bounded Confidence) | FDE-LLM (CA+SIR) |
|----------|---------------------------|-------------------|
| **舆论分布** | 所有 ABM Agent 的意见值 [-1,+1] 构成整体分布，是模拟最终要测量的因变量 | 元胞自动机的局部意见簇形成全局极化/共识格局 |
| **信息环境** | — | 邻居意见加权聚合后，影响 LLM Opinion Leader 的决策输入 |
| **内容消费** | 推荐系统根据意见距离决定 ABM Agent "看到"什么内容，进而影响其意见更新 | — |
| **衰减效应** | — | SIR 的意见衰减模拟"没人讨论后话题自然冷却"的舆论规律 |
| **极化/共识涌现** | BC 模型的 ε 阈值决定最终是一个意见簇还是多个极化簇 | CA 的局部传播 + ε=0.5 阈值，模拟信息茧房效应 |

### 4.2 具体例子

假设 FDE-LLM 模拟"疫苗争议"话题：

1. **LLM Opinion Leader** 发布反疫苗帖子，获得 500 赞
2. **CA Followers**（10,000 人）没有人评论、没有人点赞，但：
   - 帖子出现在其邻居的"信息视野"中
   - 与帖子意见距离 < ε=0.5 的人，意见值向帖子方向移动
   - 与帖子意见距离 > ε=0.5 的人，不受影响
3. 一轮传播后，**整体意见分布均值从 +0.1 漂移到 -0.15**
4. 这个宏观分布的变化就是 Follower 的"影响力"——**没有任何可见动作，但舆论悄然右移**

## 5. 三种系统的核心差异

| | HiSim Ordinary | FDE-LLM Follower | MOSS L1-L3 |
|---|---|---|---|
| **驱动方式** | Bounded Confidence 公式 | CA + SIR 公式 | 小模型 LLM |
| **行为类型** | 数字更新（无文本） | 数字更新（无文本） | 发帖/评论/点赞/转发/引用（真实文本） |
| **态度粒度** | 连续值 [-1, +1] | 连续值 [-1, +1] | 自然语言表达 |
| **能生成内容吗** | ❌ 不能 | ❌ 不能 | ✅ 能 |
| **能响应具体事件吗** | ❌ 只能更新态度数值 | ❌ 只能更新态度数值 | ✅ 能理解事件并做出文本响应 |
| **影响力的可见性** | 宏观统计层面（意见分布变化） | 宏观统计层面（意见分布变化） | 个体行为层面（可查看用户主页、帖子历史） |
| **可解释性** | 低（无法追问个体行为原因） | 低（无法追问个体行为原因） | 高（可追溯每个用户的行为轨迹和意见变化） |

---

## 6. MOSS 的差异化优势

HiSim/FDE-LLM 的两层架构存在一个固有局限：**你无法回答"沉默大多数中某个具体的人为什么改变了想法"**，因为 ABM Agent 没有可解释的行为轨迹。

MOSS 中，即使是 L1-L3 的小模型用户：

- 可以查看其发帖历史
- 可以理解其为什么点赞了某条内容
- 可以追溯其意见变化轨迹（从自然语言表达中提取）

这对**传播机制的可解释性分析**是一个重要优势——每一个用户都是可被追问、可被追溯的"完整 Agent"。

---

## 7. 总结

HiSim 和 FDE-LLM 的 ABM Agent 的"存在意义"不是产生平台内容，而是：

1. **提供舆论的宏观统计基底**——沉默大多数的意见分布构成了社会舆论的整体图景
2. **模拟传播的涌现效应**——通过简单的局部交互规则产生极化/共识等宏观现象
3. **为 LLM 核心 Agent 提供信息环境**——邻居的意见聚合影响 LLM Agent 的决策

而 MOSS 选择了另一条路线：用分层 LLM（大模型 + 小模型）替代纯数学 ABM，使所有用户都能产生可解释的行为轨迹。
