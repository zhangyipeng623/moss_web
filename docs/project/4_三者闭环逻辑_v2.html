4. 两步法评分统一公式

4.1 统一公式

离线 ABM 与在线 Feed 共享同一个两步法评分框架：

第一步 — Per-Batch Min-Max 归一化：

for each dimension d in {interest, pop, time, rand}: norm_d = (raw_d - min(raw_d)) / (max(raw_d) - min(raw_d) + ε) if max ≈ min: norm_d = 0.5

第二步 — 加权求和：

score = W_BELIEF * norm_interest + W_POP * norm_pop * TIER_WEIGHT[tier] + W_CHRONO * norm_time + W_RAND * norm_rand

离线 ABM 与在线 Feed 的唯一差异在于：ABM 中 POP 和 TIME 维度不做 Min-Max（已是标量），而在线 Feed 中对全部四维做 Min-Max。这不影响参数语义，因为校准和运行时使用的是同一个加权求和框架。

4.2 为什么 Min-Max 归一化是必需的

  • 量纲统一：interest（余弦相似度 0-1）、POP（log 归一化 0-1）、time（指数衰减 0-1）、random（均匀分布 0-1）虽然范围都在 [0,1]，但分布形态各异
  • 权重可解释：归一化后各维度均值为 0.5 附近，权重可直接解释为"该维度对最终得分的相对贡献"
  • 离线在线一致：ABM 校准时使用的归一化方式与在线 Feed 运行时一致，确保权重语义不变

6. 闭环使用工作流

6.1 完整工作流（端到端）

# Step 1: 生成用户画像（批量模式，自动 P84 分级） uv run python -m analysis.run_analysis portrait \ --data-path data/raw/ --batch # Step 2: 可选 — 重新分级（新增用户后） uv run python -m analysis.run_analysis retier \ --portraits-dir analysis_outputs/portraits/ # Step 3: 推荐参数反推（ABM + EM 校准 → 生成 calibration_profile.yaml） uv run python -m analysis.run_analysis recommender \ --data-file data/content_obs.xlsx \ --portraits-dir analysis_outputs/portraits/ # Step 4: 编辑 calibration_profile.yaml 的 experiment section # （配置 LLM、agents_csv、时间参数等） # Step 5: 启动在线模拟 python main.py --config analysis_outputs/portraits/calibration_profile.yaml

6.2 迭代循环

闭环支持快速迭代：修改数据 → 重新运行 Step 1-3 → calibration_profile.yaml 自动更新 → Step 5 重启即可应用新参数。无需修改任何代码。

关键约束：calibration_profile.yaml 的 experiment section 需要用户手动编辑（LLM 配置、agents_csv 路径等属于运行环境相关参数，不应由离线校准自动决定）。recommender section 由 EM 校准自动生成，不应手动修改。

7. Per-Batch Min-Max 归一化方法论

7.1 设计原理

Per-Batch Min-Max 归一化是一种局部归一化策略：每次 Feed 请求（或 ABM 仿真步）独立对当前批次的所有候选做 Min-Max 归一化。

  • 局部性：归一化范围仅限于当前批次，不跨批次、不跨用户
  • 鲁棒性：当批次内所有值相同时（方差 < eps），返回 0.5（中位值），避免除零
  • 可并行：各批次独立，无需全局统计量，适合向量化计算

7.2 与全局归一化的对比

特性Per-Batch Min-Max全局 Min-Max / Z-score
计算依赖仅需当前批次数据需要全局统计量（均值/方差/min/max）
实时性适合流式/在线场景需要预计算或定期更新
分布保持保持批次内相对排序保持全局相对排序
ABM 兼容性天然适合（每步一批）需要模拟全局统计量

选择 Per-Batch Min-Max 的核心原因：ABM 仿真中每步的候选集是动态变化的（取决于当前感染状态），不存在固定的"全局"候选集，因此局部归一化是唯一一致的选择。
