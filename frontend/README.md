# MOSS Web Frontend

这是 MOSS Web 的前端源码目录。

## 作用

前端主要用于展示实验过程中的帖子流、系统时间和行为轨迹。开发时在本目录下修改源码，实验运行时由后端直接加载构建后的静态资源。

## 开发态与运行态

- 开发态：使用 Vite 本地开发服务器，便于快速调试界面。
- 运行态：构建产物直接输出到 `backend/static/`，由 FastAPI 直接提供访问。

这意味着：

- `frontend/src/` 是前端源码
- `backend/static/` 是后端实际使用的静态资源
- 不再额外维护一份独立同步的静态产物目录

## 接口访问

前端默认通过 `/api` 代理访问后端接口。开发态由 Vite 代理到本地后端，运行态由同一后端进程同时提供页面和接口。

## 主要脚本

- `dev`：启动前端开发服务器
- `build`：构建前端，并直接写入 `backend/static/`
- `lint`：执行前端代码检查
- `preview`：本地预览构建结果

## 注意事项

- 修改前端后，如果要在实验运行中看到最新页面，必须重新构建。
- 后端只读取 `backend/static/` 中的内容，不读取 `frontend/src/`。
- 如果构建失败，后端可能继续使用上一次成功构建的静态资源。
