# 推荐校准数据拆分与对比实验技术方案

> 状态：Design Review 通过；依据用户“没有问题就直接写实现计划”的条件授权进入 Plan。尚未批准代码实施。
> 日期：2026-09-06。目标：独立准备数据、使用全部训练样本拟合公共基础概率和推荐系数，在固定测试集上比较两组系数。

## 1. 用户、问题与目标

使用方是进行舆情模拟与推荐机制研究的实验人员。当前 `analysis/run_analysis.py` 将数据导入、筛选、训练和留出评估放在同一入口；`analysis/recommender_parameter_inference.py` 的 M 步默认最多使用 20 条内容，留出评估又利用留出内容的真实结果拟合逐条 `p_base`。这不能直接作为未见内容的预测成绩。

可观察目标：筛选结果可保存复用；每个优化 trial 使用全部训练推文；训练不读取测试结果；两组系数使用同一测试集、基础行为概率和模拟环境，产出逐条误差及汇总对比。

## 2. 功能与范围

| 需求 | 本次交付 |
|---|---|
| 筛选从校准中移出 | 独立数据准备脚本，保存数据、划分和缩放规则 |
| 所有推文参与训练 | 输入训练文件中的每条推文都参与公共概率拟合和每次权重优化，无 20 条上限 |
| 确定测试集基础概率 | 训练阶段拟合一个公共 `p_base`，测试阶段冻结 |
| 对比另一系统系数 | 独立实验入口导入系数，在同一模拟器与测试集上比较 |
| 查看误差或正确程度 | MAE、RMSE、非零目标 MRE、误差达标率、逐条 CSV 和敏感性结果 |

本次不实现特征预测型 `p_base`、早期传播预测、真实推荐曝光干预、用户级 Precision@K、前端页面或论文生成。不改在线推荐打分公式或 LLM Agent 行为。另一系统按系数文件接入，不调用其服务。

## 3. 整体设计

```text
原始 CSV/XLSX 或 records JSON
  → prepare_recommender_data：校验、去重检查、固定划分
  → 仅训练分区拟合缩放锚点、筛选和可选分层抽样
  → train.json + test.json + manifest.json
train.json + 用户画像 → recommender → model.json + calibration_profile.yaml
model.json + test.json + 对照系数 JSON + 同一画像
  → compare_recommenders → summary.json + per_story.csv
```

单一业务不变量：任何测试结果不得参与数据缩放参数、公共概率、权重或实验超参数的拟合。训练入口不自动运行测试；比较入口不优化参数。

### 3.1 职责落点

| 文件 | 职责 |
|---|---|
| `scripts/prepare_recommender_data.py`（新增） | 独立 CLI，调用准备逻辑，导出固定数据包 |
| `analysis/recommender_data.py`（新增） | 原始字段转换、数据契约、划分、训练侧筛选与缩放、数据包校验 |
| `analysis/run_analysis.py`（修改） | recommender 只编排训练；移除筛选与自动留出评估调用 |
| `analysis/recommender_parameter_inference.py`（修改） | 复用画像、ABM、Optuna；公共概率与全量训练，不承担数据筛选和主实验编排 |
| `analysis/compare_recommenders.py`（新增） | 固定参数模拟、指标、敏感性实验及导出 |
| `core/calibration_profile.py`（修改） | 增加可选公共概率元数据，兼容现有 YAML |
| `analysis/README.md`（修改） | 三阶段命令、迁移与指标解释 |

复用现有 NumPy、pandas、SciPy、Optuna、joblib 与嵌入处理；不增加依赖，不引入插件系统或通用实验框架。

## 4. 数据接口、划分与所有权

### 4.1 准备入口

拟提供：

```bash
uv run python scripts/prepare_recommender_data.py --data-file data/posts.xlsx --text-column 正文 --num-agents 1500 --output-dir analysis_outputs/datasets/example
```

支持 CSV/XLSX 和带 `records` 数组的 JSON。表格列参数沿用 `--retweet-columns`、`--view-column`、`--id-column`，增加必填 `--text-column`；JSON 使用 `story_id/text/repost_count/view_count`。表格缺列须报错，不能把缺列当作零。数值必须有限且非负；浏览量为零的记录排除并计数。空 ID、重复 ID、空正文及无法解析的数值报错并定位行号，不静默覆盖或伪造正文。重复推文须先由使用方确认合并规则。

默认以 ID 排序后使用种子 42 做 70% 训练、30% 测试划分：`n_test=max(1, round(n*0.3))`，至少两条数据，两分区均非空。命令可指定 `--test-ratio`（严格在 0 与 1 之间）、`--random-seed`。本版不新增独立调参集；所有算法预算和敏感性网格预先固定。若后续据测试结果改方案，必须另留未使用的数据作最终测试。

划分在基于传播量的筛选和缩放前完成。测试分区保留零转发和低传播内容，不应用训练筛选。默认训练过滤规则沿用转发量 >0、浏览量 >100、缩放目标 ≥5；只影响训练文件。`--selection all` 默认保留所有达到训练过滤条件的记录；`--selection stratified` 显式开启现有十档抽样逻辑，样本量不超过有效记录数，固定随机种子。筛选后训练集为空时报错。

### 4.2 缩放与目标

在训练分区中满足转发量 >0、浏览量 >100 的记录上，以浏览量 80% 分位数确定锚点；锚点与计算样本 ID 固化在 manifest。比例 `scale_ratio=num_agents/anchor`，训练和测试都使用 `scaled_target=min(round(repost_count*scale_ratio), num_agents)`。训练集进一步按目标 ≥5 筛选；参数 `--anchor-percentile` 和 `--min-scaled-target` 在准备时可覆盖，必须记录。

不得根据测试数据重算锚点。输出保留 `unclipped_target` 和 `target_clipped`；汇总报告两分区的截断数量，避免把人口上限造成的误差缩小解释为预测进步。主指标使用模拟规模的目标，报告不能称其为原始真实转发次数误差。

### 4.3 数据包契约

`manifest.json` 包含 `schema_version=1`、原始文件 SHA-256、字段映射、清洗计数、划分种子/比例、两分区 ID、选择策略、锚点/比例、人口规模、训练/测试记录数和各文件 SHA-256。文件散列对最终文件字节计算；manifest 不包含自身散列。

`train.json` / `test.json` 包含 `schema_version=1`、`split=train|test`、`num_agents`、`scale_ratio` 和 `records`；每条包含 `story_id`、`text`、`repost_count`、`view_count`、`scaled_target`、`unclipped_target`、`target_clipped`。记录按 ID 排序。训练器只读取 train 和 manifest 中训练所需元数据，不打开 test 文件；比较器核对 test 文件散列、模型记录的训练 ID 和测试 ID 无交集。数据包中任何记录变动都须重新准备，不允许静默重新划分。

数据准备模块拥有派生数据格式；原始数据、画像及既有运行档案始终只读。

## 5. 全量训练与公共基础概率

### 5.1 训练接口

```bash
uv run python -m analysis.run_analysis recommender --train-file analysis_outputs/datasets/example/train.json --portraits-dir data/portraits --output-dir analysis_outputs/calibration/example
```

`--train-file` 必需，相邻 `manifest.json` 必须存在。人口规模从数据包读取；画像必需且不能是空目录。沿用嵌入模型、CPU、随机种子、最大迭代次数、时间尺度和轮数参数。默认 3 轮交替优化、每步 3600 秒、24 步；`duration` 统一表示模拟步数，小时数由步数乘时间尺度推导，不能保留默认 24 覆盖 CLI 的路径。

### 5.2 拟合方法与损失

公共 `p_base` 是所有训练推文共用的标量，不是逐条概率的平均值。采用交替优化：固定权重与衰减参数优化公共概率，再固定公共概率优化四项权重及衰减参数。这里不宣称具有严格 EM 的概率模型推导；文档称为“公共概率与推荐参数交替校准”。

两步都使用相同的目标：

`L = mean_i(mean_r(abs(simulated_final[i,r] - scaled_target[i]) / num_agents))`

每条训练推文等权，每个 trial 完整遍历全部训练 ID，默认重复 5 次。公共概率搜索 `[0.001,0.999]`（与 ABM 实际截断区间一致），20 trials；权重四个非负参数归一化、总和为 1，50 trials，衰减搜索沿用 `[0.01,3.0]`。全零权重候选拒绝。采用统一计数损失是为了避免公共概率和权重分别优化转发率、转发量两个不同目标；公共概率不再解释为直接测得的真实转发率。

保留当前初始权重 0.35/0.25/0.25/0.15 和衰减 0.5。随机种子显式传给 Optuna sampler；每条推文和重复序号使用稳定种子，trial 间复用随机种子以减小优化噪声。每轮记录参与 ID 数、损失、参数、耗时，保存全轮最佳成对参数，最终按相同种子重放核对损失。不得将不同轮的 `p_base` 与权重拼接。

全量训练也覆盖训练侧消融与鲁棒性诊断；现有最多 20 条等诊断抽样不得用于发布全量成绩。训练 CLI 不再隐式运行这些实验，额外诊断须显式调用并注明用途。

### 5.3 模型产物

`model.json` 为比较器的权威输入，包含：版本、训练文件/manifest 散列和训练 ID；规范化权重；`decay_lambda`；`p_base_mode=global` 与 `p_base_global`；训练损失定义/预算/种子/逐轮诊断；完整 ABM 设置（人口、时间尺度、步数、在线概率、信念参数、层级权重）；画像文件清单与散列、嵌入模型及版本信息。

并写 `calibration_profile.yaml`，沿用现有线上字段，在 recommender 段增加可选 `p_base_global`，旧文件缺少该字段仍可加载。新模型的 `calibrated_p_base` 留空，不伪造逐内容结果。公共概率供离线实验使用，本次不把它接入在线 LLM 行为；在线推荐继续只消费其现有配置字段。

## 6. 同一测试集上的系数对比

### 6.1 实验入口与对照系数

```bash
uv run python -m analysis.compare_recommenders --model analysis_outputs/calibration/example/model.json --test-file analysis_outputs/datasets/example/test.json --baseline data/baseline.json --portraits-dir data/portraits --output-dir analysis_outputs/comparison/example
```

baseline JSON 使用唯一字段格式：`name`、`weights`（`w_interest/w_popularity/w_time/w_random`）和可选 `decay_lambda`。四项必须有限、非负、总和大于零，输入后归一化并同时记录原值和归一化值；未知字段或缺项报错。省略衰减时共用本模型衰减，此时比较标签为“仅权重”；提供衰减时标签为“权重及衰减参数”。不能通过默认值补齐缺失权重。

另一系统系数必须已能对应上述四项及相同评分语义。公式、特征归一化或维度不同的系统不在本版自动转换；导入数据由实验者提供，结果明确为“本 ABM 下的参数替换实验”，不等于运行了另一系统的完整推荐机制。

### 6.2 固定条件与随机性

重建种群与扩增兴趣必须使用模型保存的训练种子，比较种子只控制重复模拟及统计重采样。画像按文件相对路径排序加载，模型记录实际加载文件的清单及散列。画像清单/散列、嵌入模型、人口规模、在线概率、信念参数、层级权重、步数和时间尺度均从模型继承并校验，不能由对照文件覆盖。每条测试内容预计算一次兴趣向量，两组共用；每次模拟重新初始化状态。

主实验两组使用训练产物中的同一个 `p_base_global`。比较模块禁止调用 E 步或 Optuna，不读取测试结果拟合任何值。默认每条每组重复 30 次，可用 `--n-repeats` 增加但不得小于 30；比较种子默认 2026，可显式设定并记录。稳定种子仅由实验种子、推文 ID、重复序号构成，不包含模型名或 `p_base`。两组种子相同不保证分支后的随机事件逐个对应，不能宣称完美随机数配对。

### 6.3 指标与导出

令 `y_i` 为缩放目标，`m_i` 为该组 30 次模拟终值的均值：

| 字段 | 定义 |
|---|---|
| `mae` | `mean(abs(m_i-y_i))`，包括零目标 |
| `rmse` | `sqrt(mean((m_i-y_i)^2))`，包括零目标 |
| `mre_nonzero` | `mean(abs(m_i-y_i)/y_i)`，仅 `y_i>0`；全零时为 null |
| `relative_pass_rate_nonzero` | 非零目标相对误差 ≤阈值的比例，默认阈值 0.2；全零时为 null |
| `absolute_pass_rate` | 全样本绝对误差 ≤阈值的比例，默认阈值 1 个模拟用户 |

阈值由比较 CLI 的 `--relative-threshold`、`--absolute-threshold` 在运行前确定，必须有限且非负。报告同时列全样本数、非零样本数、零目标 MAE 和截断数，禁止以极小分母掩盖零目标。误差达标率不称为推荐准确率。

`summary.json` 包含输入指纹、完整运行配置、两组指标、差值和敏感性结果。误差改善定义 `baseline_error-candidate_error`；相对改善除以 baseline_error，基线误差为零时为 null。按推文进行配对 bootstrap（2000 次，固定种子）给出 MAE 差的百分位 95% 区间；测试少于两条时区间为 null。它只描述固定训练产物与当前测试采样下的不确定性，不涵盖重新训练方差；相关事件数据不能据此声称独立样本显著性。

`per_story.csv` 每行是一条推文、一个实验条件和一组系数，包含 ID、条件、`p_base`、组名、目标、预测均值/标准差、绝对误差、相对误差（零目标留空）、两类达标标记、重复次数及截断标记。正文不重复导出；字符串按 CSV 规则转义，并防止以 `= + - @` 开头的外部字符串被表格软件解释为公式。

### 6.4 公共概率敏感性实验

默认附加固定网格 `[0.001,0.01,0.05,0.1,0.3,0.5,0.9,0.999]`；命令可用 `--p-base-grid` 提供运行前确定的非空有限值集合，范围同训练。对每个值，两组都使用相同概率、相同重复数和种子，不重新训练权重。报告全部结果和优劣方向，不选择测试集最优概率覆盖主实验。主实验值与网格相同时复用结果。

公共概率和本组权重联合拟合可能更适配本组；敏感性实验用于揭示比较结论对该假设的依赖，不消除模型偏差。未来若引入独立行为数据或特征预测器，应另立方案。

## 7. 状态、失败、安全与兼容

产物状态为准备中、完成或失败；只有全部文件成功写入才发布目标输出目录。输出路径必须不存在，已存在则报错，不覆盖旧实验。写入同父目录的普通临时目录，完成后重命名；失败清理本次临时产物，保留原始数据。没有自动续跑或数据库事务；同一输出路径并发执行最多一个成功，另一进程明确报错。

数据缺失、散列/人口/画像不一致、训练测试交集、模型版本不支持、非有限预测、嵌入加载或优化失败均以非零退出码结束，错误包含文件/字段/阶段和原始原因。不能跳过失败推文后发布整批成功结果。日志记录数量、阶段、耗时和当前轮次，不打印正文、画像内容或密钥。

这是本地 CLI，无新增 HTTP API、身份系统或权限。仅读用户指定文件和已有模型资源；不调用聊天模型 API。嵌入资源沿用现有加载机制，首次下载仍可能联网。

兼容迁移：recommender 的旧 `--data-file/--input` 及筛选参数停止接受训练，给出运行准备脚本的明确迁移错误，不静默沿用旧筛选。准备脚本提供原表格输入能力；现有画像命令不变。旧 YAML 继续供 `main.py` 使用；旧推断 JSON 因缺少公共概率与数据指纹不能直接作为新比较模型，须重新训练。旧留出诊断作为历史输出保留，但不汇入新主实验。

回退只需恢复相关源码并重新使用旧命令和旧档案；新产物使用独立目录，不修改历史文件或数据库。恢复源码不得覆盖用户其他本地修改。现有线上 YAML 字段增量可忽略，公共概率不改变在线动作语义。

## 8. 性能、可观测性与科学边界

训练成本随完整训练样本数线性增加：约 `轮数×(20+50)×训练数×5` 次 ABM 模拟；比较约 `2×测试数×30×(1+网格数)` 次，重复条件可复用。已有 CPU 并行用于独立模拟任务，按任务种子确定结果，避免共享可变引擎；不通过抽样降低已承诺的全量覆盖。兴趣向量只在当前进程预计算，内存约与推文数×人口规模成正比；本版不新增跨运行缓存。

运行前打印预计模拟次数，运行中记录阶段、完成数、耗时和样本覆盖数。大输入内存不足或用户中断时明确失败，不自动降人口、换模型或缩样本。

本版终点是缩放后的传播总量，不接入轨迹损失。只有横截面总量时，四维权重和衰减继续按现有搜索空间作为有效拟合参数，不声称辨识真实时间机制。模拟器有初始传播种子，零目标可能存在不可消除的误差，应如实保留。随机划分可能让相似事件跨集合，本实验仅支持同源内容留出结论；跨事件或跨时间泛化需要另行分组数据协议。

## 9. 关键决策

| 决策 | 理由与放弃方案 | 后果 |
|---|---|---|
| 准备、训练、比较分开 | 避免每次训练重新筛选/切分 | 固定数据文件成为实验输入 |
| 训练全量，测试独立 | 不再用最多 20 条代表训练成绩 | 耗时增加，必须报告覆盖 |
| 训练公共概率，测试冻结 | 放弃验证结果反推概率及逐条均值捷径 | 控制变量明确，丢失内容异质性 |
| 两步统一缩放计数损失 | 不沿用公共概率拟合率、权重拟合量的双目标 | 旧损失与新成绩不可直接比较 |
| 测试不做传播量筛选 | 防止只在高传播内容上报告成绩 | 必须处理零目标和截断 |
| 保留时间参数搜索，限制解释 | 本次不扩大为时间机制识别研究 | 不报告真实系数恢复准确率 |

## 10. 验证与验收

| 验收点 | 可重复验证 |
|---|---|
| 数据没有泄漏 | 改动测试转发量不改变训练文件、锚点与训练参数；准备固定种子重放同一划分 |
| 正文和 ID 保真 | 中英文 CSV/XLSX/JSON 小样本；缺列、空正文、重复 ID 明确失败 |
| 全量训练 | 构造 25 条训练记录，捕获每个概率及权重 trial 的参与 ID，必须为完整 25 条 |
| 冻结公共概率 | 比较时将优化入口替换成抛错函数仍可执行；更换测试目标不改变模拟预测，只改变误差 |
| 两组比较一致 | 相同系数时逐条预测及指标相同，MAE 差为零；画像/人口冲突拒绝运行 |
| 指标可靠 | 手算包含零目标的均值误差、RMSE、阈值达标率；全零和单条区间返回规定 null |
| 敏感性无择优 | 输出全部网格，主实验参数保持模型值，错误参数明确失败 |
| 持久化与兼容 | 中断、输出已存在、损坏散列无成功产物；旧 YAML 可解析；旧 CLI 有迁移错误 |

实现阶段以标准库 unittest 或可重复脚本建立上述回归，先观察失败再实现；不依赖网络的测试用确定性小型引擎/向量。另用本地可用的真实 ABM 与小规模画像跑训练→比较冒烟，保存输入与产物；完整真实数据实验不作为代码正确性已经证明的替代。

最低检查为修改 Python 文件的 `.venv/bin/python -m py_compile`、新增回归脚本以及 `git diff --check`。无前端改动，不运行前端构建。没有可用嵌入资源时明确记录真实集成验证缺口，不把替身测试写成完整集成通过。
