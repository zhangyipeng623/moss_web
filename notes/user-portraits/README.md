## 当前定案

收录当前代码中的画像生成、画像模式与分层事实，未补造历史审批。状态保留为 `in-progress`：已有实现，但本轮未运行模型或验收用户原有修改。

- [画像生成器](../../analysis/user_portrait_generator.py) 保留证据、稳定画像、行为画像、Agent 画像与模拟初始状态五类产物；当前 `run_pipeline` 将行为与 Agent 画像合并为一次生成阶段，并保留阶段重试。
- [离线入口](../../analysis/run_analysis.py) 支持单用户、批量与 `retier`；批量和重分层按 P84 切分 L4/L5，已有画像可跳过生成并更新层级，失败用户写入名单。
- 当前本地增量包括批量 `--concurrency`（默认 10）、默认开启的 JSON Schema 输出及调用失败后的纯文本回退、显式参考时间与生成元信息。参考时间未提供时会交互输入，不能直接假定批处理全程无人值守。
- [画像解析器](../../core/agent_profile_resolver.py) 与 [配置模型](../../core/experiment_config.py) 支持 `default/custom/simple`；画像模式与 `tier` 分别控制画像来源与层级，不混为单一开关。

背景见 [原用户画像文档](../../docs/projects/01_用户画像.md)。其中“五阶段”应区分产物结构与当前调用阶段，运行细节以代码为准。输入衔接 [数据准备](../data-preparation/README.md)，输出用于 [推荐参数校准](../recommender-calibration/README.md) 与 [Agent 社交模拟](../agent-simulation/README.md)。
