## 当前定案

现有研究文档将课题聚焦于推荐机制校准与大小模型分层仿真。这里收录既有研究范围和待验证问题，尚未形成新的获批实验方案。

[研究总览](../../docs/plan/研究总览_创新点与验证.md) 采用横截面传播总量的假设，围绕分布、排序与留出验证展开；没有时间序列时，不将时间衰减参数作为已辨识结论，也不声称验证了传播动力学。

该文档同时存在“保留四维搜索、声明弱辨识”和“时间参数作为先验常数”的不同表述。实施实验前需明确搜索空间与论文表述，不能视为同一项已批准策略。[数据准备](../data-preparation/README.md) 中出现时序转换脚本，也不足以自动改变研究范围。

[论文待办](../../docs/plan/论文写作与后续工作待办.md) 包含全员大模型与大小模型分层的对照、画像措辞扰动和统计检验表述；[下一步对话](../../docs/plan/下一步对话.md) 另列推荐对标、矩阵运算时效性、五层用户、羊群效应与信息茧房。这些是候选工作，不是已证明结论或获批计划。
